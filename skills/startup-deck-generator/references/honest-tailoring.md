# Honest tailoring

Tailoring a deck per investor is normal, useful, and expected. It is also one step
away from something that ends a fundraise, so the line is worth stating precisely
rather than leaving to instinct.

## The line

**Tailoring changes how the argument is presented. It never changes what is true.**

| Legitimate — change freely | Off-limits — never varies by audience |
|---|---|
| Slide order and what leads | Any metric value |
| Headlines and framing | The definition behind any metric |
| Which proof point goes first | Round size, valuation, structure, terms |
| Vocabulary and terminology | Competitive claims |
| Which slides exist; which are cut | Customer names, logos, or status |
| Depth of detail on a given point | Team credentials, titles, commitments |
| Objections pre-empted on-slide | Timelines and shipped-vs-planned status |
| Emphasis on impact, market, or team | Anything in a signed document |

If a proposed change lands in the right-hand column, it isn't tailoring.

## The trap worth naming explicitly

The most likely failure isn't a fabricated number. It's a **shifting definition**.

A founder pitching a growth-focused fund is tempted to let ARR include signed LOIs.
Pitching a discipline-focused fund the same week, they use contracted revenue only.
Neither number is invented. Both are defensible in isolation. Together they are
misrepresentation, because the same label now denotes two different things to two
parties evaluating the same round.

This is easy to walk into precisely because each step feels reasonable. The rule that
prevents it: **pick a definition once, state it on the slide, and use it with everyone.**
If a definition genuinely needs to change, it changes in every version of the deck,
including the ones already sent.

## Why this is practical, not just principled

Worth stating for the founder who thinks of this as an ethics lecture rather than
advice.

Investors talk. Co-investors in a syndicate compare notes and compare decks. Diligence
reaches the data room, and the data room contains one set of numbers. References get
called. A metric that shifted between two decks surfaces at the worst possible moment
— during diligence on a term sheet, when the cost is not a lost meeting but a
withdrawn offer and a story that travels.

The asymmetry is stark: the upside of an audience-flattering number is a slightly
better meeting; the downside is the round. Tailoring emphasis captures nearly all of
the upside and carries none of that risk.

## What to do when asked to change a number

Founders ask for this, usually without meaning anything by it — "can we show them the
higher figure, they only care about growth." Treat it as a framing problem, because
that's almost always what's underneath.

Decline the number change, name why in one line, then offer the thing they actually
wanted: lead with the growth-rate proof point, add a trajectory chart, cut the slide
that undercuts it, restructure the deck so the strong fact arrives earlier. Emphasis
is where the real leverage was anyway.

If the founder wants a genuinely different metric shown — not a different value for
the same metric — that's fine and often good. Show contracted revenue *and* pipeline
as two clearly labelled things. Two honest numbers beat one flattering one.

## The flag convention

Reused verbatim from `pitch-content-guide` — deliberately, because a second convention
in one bundle guarantees one of them gets ignored.

Any number, date, customer name, or claim not confirmed from a source gets flagged
inline:

```
[REVIEW: confirm round size and structure]
```

Render these **in red**, count them, and state the count when handing off. An
uncounted flag is a flag that gets skipped, and a flag that reaches an investor is
worse than the gap it was marking.

This convention is what makes it safe to build a deck before every number is settled,
which is most of why the skill is useful early rather than only at the end.

## Label the artifact

Every tailored deck gets a line on the cover:

```
Prepared for <Investor> · Confidential
```

Two reasons. It stops the wrong version being forwarded to the wrong fund, which is a
real and recurring accident once four tailored versions exist. And it makes the
tailoring visible rather than furtive — an investor who can see the deck was prepared
for them reads it as diligence, whereas one who discovers it was reads it as
something else.
