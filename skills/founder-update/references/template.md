# Founder update — full template reference

Two layouts are in common use. Both carry the same content; pick whichever the company
already uses (read their prior doc in Step 1). If they have no prior update, default to
**Layout A (table)** for monthly, **Layout C (lightweight)** for weekly.

---

## Layout A — Category / Update table

A two-column table. Left = category (with its prompt), right = the founder's content.
Skippable rows are dropped entirely when empty.

```
DATE: {Month Day, Year}    [** CONFIDENTIAL **]

| Category | Update |
| --- | --- |
| General update — 2–4 sentences: the period in one breath, biggest win, biggest concern. | … |
| Progress on OKRs — Objectives and Key Results, numeric. | (OKR block — see below) |
| Product & Technology — customer feedback, demos, shipped features, photos/renderings. | … |
| Traction & Business Development — inbound leads, funnel conversion, LOIs, contracts, top deals with $ values. | … |
| Money in the bank & runway — Cash on Hand; Monthly Burn; Runway (months). | (always present) |
| Market — TAM/SAM developments, new segments, geographies, pricing. | … |
| Competition — competitive shifts, wins/losses, moat. | … |
| Impact — GHG/climate metrics tied to the climate thesis. | … |
| Fundraising — inbound interest, grants, term sheets (only if active). | … |
| Team updates — hires, departures, role changes, needs. | … |
| Help & Asks — running list; intros, term-sheet reviews, hiring. Keep old asks until done. | … |
| Other — press, social proof, photos, people to thank. | … |
```

## Layout B — Narrative letter + dashboard

```
{Month} {Year} Update
{send date}
** CONFIDENTIAL **

Dear Investors and Advisors,

Major Changes This Period
  • …

Where We Stand
  • Headline metrics as a short bulleted list (signed deals, pipeline, revenue YTD,
    cash, burn, runway).

Primary Risk
  • The single biggest thing that could go wrong + mitigation.

How You Can Help
  • The running asks list.

Core Metrics Dashboard
  (the table below)
```

## Layout C — Lightweight weekly

```
{Company} — Week of {date}
• General update (2–3 sentences)
• OKR deltas only (KRs that moved, with the new number)
• Metric chart (headline metric)
• New asks + still-open asks
```

---

## OKR block format

Objectives are qualitative; Key Results are always numeric (current / target) with a
status glyph. A short parenthetical on any off-track KR (why + recovery plan).

```
Objective 1 — {objective}
  • KR1: {metric} — {current} / {target} {🟢|🟡|🔴}
  • KR2: {metric} — {current} / {target} {🟢|🟡|🔴}  ({one-clause why + plan})

Objective 2 — {objective}
  • KR1: …
```

Status glyphs: 🟢 on track · 🟡 at risk / behind pace · 🔴 off track or stalled.

If the company tracks OKRs in a linked sheet (common), summarize the moved KRs inline
and link the full sheet rather than transcribing the whole thing.

---

## Core Metrics Dashboard

The single most useful object in the update. Always include `Current` AND `Last period`
so the delta is visible, plus the `Target`. Status glyph on each row.

```
| Metric            | Status | Current        | Last period   | Target          |
| ----------------- | :----: | -------------- | ------------- | --------------- |
| Qualified leads   |   🟢   | 11             | 8             | 15              |
| Pipeline ($)      |   🟢   | $550K          | $350K         | —               |
| Signed deals      |   🔴   | 0              | 0             | 4               |
| ARR               |   🔴   | $0             | $0            | Path to $1M     |
| Revenue (YTD)     |   🟡   | $115K          | $100K         | $200K           |
| Cash on hand      |   🟢   | $730K          | $420K         | —               |
| Monthly burn      |   🟢   | $60K           | $90K          | ~$60K           |
| Runway (months)   |   🟡   | 11             | 7             | into 2027 w/ rev|
| Headcount         |   🟢   | 3 FTE          | 1 FTE         | 3 FTE           |
```

Pick the rows that matter for this company; runway always appears. Keep the metric set
stable period-to-period so the dashboard reads as a time series.

## Subsection guidance

Each body subsection maps to a core dimension of business progress. Skip any subsection
with nothing notable this period — a blank header is noise.

**Product & Technology** — shipped features, technical milestones, product-market fit
signals, customer feedback.

**Traction & Business Development** — inbound leads, pipeline ($), signed deals, LOIs,
conversion rates, time-to-revenue.

**Market** — TAM/SAM developments, new market segments, geographic expansion, pricing
changes.

**Competition** — competitive shifts, wins/losses vs. incumbents, defensibility / moat.

**Impact** — GHG/climate metrics, milestones tied to the climate thesis.

**Team** — hires, departures, key role changes, open hiring needs, advisor additions.

**Financial & Runway** — cash on hand, monthly burn, runway in months, path to breakeven
/ profitability.

---

## Tone

The founder's voice — direct, specific, confident but honest about risk. No hype words
without a number behind them. Investors reading 20 of these a month reward signal and
punish padding.
